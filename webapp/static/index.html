Does the web search actually earn its place?

We built a five-case benchmark of real, documented, post-cutoff API breakages (across NumPy, pandas, Pydantic, Flask, and the standard library) and run the identical loop with Tavily on and off. The gap between the two is the value the live web adds. The harness ships an offline self-test, so the measurement is trustworthy before a single paid token is spent.
